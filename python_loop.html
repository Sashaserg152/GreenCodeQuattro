Алгоритмическая конструкция с предусловием

Алгоритм — понятная и конечная последовательность точных действий (команд), формальное выполнение которых позволяет получить решение поставленной задачи. Команда в алгоритме — указание на выполнение конкретного действия.
Человеку также регулярно приходится выполнять действия исходя из тех или иных условий: взыять сонт, если пошёл дождь, пойти в магазин, если акончились продукты и др. В качестве примера Алгоритм покупки продуктов:

1. Пойти в магазин
2. Есть ли в карзине место?
а) Найти нужный товар
б) Положить его в карзину
3. Пойти на кассу оплачивать карзину

Алгоритмическая конструкция цикл с предусловием (цикл «пока») — способ организации цикла, при котором количество выполнений команд тела цикла зависит от истинности или ложности условия цикла.

При создании алгоритма рекомендуется следовать определённой последовательности:
1) Словесное решение задачи;
2) Построение блок-схемы решения задачи;
3) Написание псевдо-кода программы;
4) Запись алгоритма на языке программирования.

Алгоритм с предусловием часто необходим для программ в которых условия могут меняться в зависимости от условий среды. Это сделано для того, чтобы не переписывать код по несколько раз для каждого условия, а создания универсальной программы. Рассмотрим построение цикла с предусловием на примере решения задачи коспьютерного исполнителя Робот.

Решение программы

Для решения любой задачи в программировании необходимо сначало составить его по действиям, после при необходимости составить словесную или визуальную схему и записать саму программу. Данные действия обязательны для начинающих программистов, в дальнейшем вы сможите решать задачи путём записи его на языке программирования, без использования других представлений.
