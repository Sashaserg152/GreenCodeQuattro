Компьютерный исполнитель Чертёжник

Чертёжник — это компьютерный исполнитель, который умеет создавать рисунки, если ему указать правильные команды

Среда обитания исполнителя Чертёжник — часть координатной плоскости. Исходное положение Чертёжника — точка с координатами (0,0), перо поднято. Координатная плоскость Чертёжника по умолчанию определяется значениями первой плоскости. Размер окна Чертёжника зависит от заданной учащимися при написании программы.

Некоторые команды исполнителя Чертёжник, с помощью которых можно написать программы, представлены в таблице.

Для того чтобы Чертёжник мог выполнять команды, первой командой в программе нужно подключить модуль, содержащий команды управления Чертёжником: uses Drawman;

В качестве команд для перемещения можно использовать не только команду ToPoint, но и OnVector. Если в первом случае прямая перемещается в конкретную точку координатной плоскости, то в случае второй команды, задаётся вектор перемещения, который не зависит от координатной плоскости. Например:

Коды: Программа:
uses Drawman;
begin
Field(6,6);
ToPoint(1,2);
PenDown;
OnVector(3,5);
OnVector(4,1);
OnVector(1,2);
PenUp;
end. 		uses Drawman;
begin
Field(6,6);
ToPoint(1,2);
PenDown;
ToPoint(2,3);
ToPoint(1,-4);
ToPoint(-3,1);
PenUp;
end.
