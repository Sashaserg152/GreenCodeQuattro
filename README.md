# GreenCodeQuattro

Статический образовательный сайт: HTML, CSS и изображения. Сборка и серверное приложение не требуются.

## Публикация на GitHub Pages

После добавления изменений в `main` администратор репозитория должен:

1. Открыть **Settings → Pages**.
2. В разделе **Build and deployment → Source** выбрать **GitHub Actions**.
3. Во вкладке **Actions** открыть **Deploy static site to GitHub Pages** и нажать **Run workflow**, выбрав ветку `main`, если публикация ещё не запустилась автоматически.

В дальнейшем сайт публикуется автоматически при каждом push в `main`. Для pull request публикация не запускается.
Workflow загружает только HTML, CSS, JavaScript и каталог `img`, без служебных файлов репозитория.

Адрес сайта после успешной публикации:
<https://sashaserg152.github.io/GreenCodeQuattro/>.
Для форка адрес будет `https://<владелец>.github.io/GreenCodeQuattro/`.

`index.html` перенаправляет на `Главная.html`, поэтому существующие ссылки на главную страницу сохраняются.
Все локальные ссылки относительные и работают в подкаталоге проекта на GitHub Pages.

## Адаптивная вёрстка

На телефонах примеры с пояснениями, блок-схемами и кодом располагаются друг под другом.
`responsive.js` автоматически сохраняет названия колонок у таблиц из двух строк (заголовки и содержимое).
Остальные таблицы прокручиваются горизонтально внутри своего блока, не растягивая страницу.
Размеры картинок ограничены шириной экрана; по клику доступно увеличение.
Для служебных иконок и логотипов увеличение отключено. Чтобы отключить его у другой картинки, добавьте к `<img>` атрибут `data-no-zoom`.

## Локальный просмотр

Из корня репозитория запустите:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000/>.
