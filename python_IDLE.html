Среда программирования IDLE

Среда программирования — комплекс программ, используемых при разработке других программного обеспечения.

Для разработки программ используются среды программирования (Интегрированные Среды Разработки - ИСР, англ. IDE, Integrated Development Environment).

Для работы с языком программирования Python можно использовать среды программирования:
• среда IDLE устанавливается вместе с языком Python;
• среда PyCharm;
• онлайн-среды программирования.
• онлайн-ресурс с уроками.

При нажатии на иконку среды, открывается рабочая область которая включает в себя 2 раздела: панель управления (сверху), область для написания кода.
В панели управления находятся разделы File (Файл), Edit (Правка), Shell (Вид), Debug (Отладка), Options (Настройки), Window (Окно), Help (Помощь). С помощью панели File можно сохранять и открывать файлы. При необходимости можно обратиться к справочной системе через меню Help.
В среду программирования входят: редактор текстов, справочная система, исполнитель Черепаха и др. На странице Search page/Страница поиска можно найти интересующую информацию. Примеры можно скопировать в среду программирования и там же выполнить. Перевод на русский язык доступен в браузере из контекстного меню.
